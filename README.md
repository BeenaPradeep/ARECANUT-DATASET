# Arecanut Disease Detection Dataset – 6 Classes

## Overview

This repository contains an arecanut disease detection image dataset developed for research on automated identification and classification of diseases affecting arecanut plants.

The dataset consists of field images of healthy and diseased arecanut leaves and nuts collected in Karnataka, India. The images were manually categorized into six classes with the assistance of agricultural domain experts/farmers familiar with arecanut cultivation and disease symptoms.

The dataset is intended to support research in computer vision, deep learning, machine learning, and automated plant disease detection.

## Dataset Classes

The dataset contains six classes:

1. Bud Rot
2. Healthy Leaf
3. Healthy Nut
4. Koleroga
5. Ring Spot
6. Yellow Leaf

## Dataset Organization

The dataset is organized into separate folders according to the image class:

ARECANUT-DATASET/

├── Bud rot/

├── Healthy Leaf/

├── Healthy Nut/

├── koleroga/

├── Ring Spot/

└── Yellow Leaf/

Each folder contains images belonging to the corresponding class.

## Data Collection

The images were collected from arecanut plantations in Karnataka, India. The dataset contains field images representing healthy and diseased conditions of arecanut plants.

The images were acquired under natural field conditions to represent variations in illumination, background, plant growth conditions, and disease appearance.

## Image Annotation

The images were manually reviewed and categorized according to the visible disease condition.

Farmers with practical experience in arecanut cultivation were consulted as agricultural domain experts to assist in identifying disease symptoms and assigning the appropriate disease category.

The annotation process was limited to disease identification and image categorization. No personal or sensitive information relating to the farmers was collected as part of the dataset.

## Intended Use

The dataset can be used for:

- Arecanut disease classification
- Plant disease detection
- Image classification using CNN and deep learning
- Machine learning research
- Computer vision applications
- Feature extraction and disease recognition
- Development and evaluation of automated agricultural disease detection systems

## Classes

### Bud Rot
Images showing symptoms associated with bud rot disease in arecanut.

### Healthy Leaf
Images representing healthy arecanut leaves without visible disease symptoms.

### Healthy Nut
Images representing healthy arecanut nuts/fruits.

### Koleroga
Images showing symptoms associated with Koleroga disease.

### Ring Spot
Images showing characteristic ring-spot symptoms on arecanut leaves.

### Yellow Leaf
Images showing yellowing symptoms associated with yellow leaf disease.
